# Login Screen – Visual Mockup (Phase 1)

Static HTML/CSS mockups for the **Login Screen**. No JavaScript, no backend, no logic.

## How to view

Open in a browser (double-click or `file:///...`):

- **`index.html`** – Default state (no error)
- **`index-error-state.html`** – Failure state with clear error message

## Contents

- Restaurant logo placeholder (replaceable icon area)
- System name: **Shawarma Basel POS** + **نظام إدارة مطعم شاورما**
- Username and password fields (RTL, masked password)
- **دخول** (Login) button
- Error message area (visible in `index-error-state.html`: wrong credentials, remaining attempts)
- Hint: "اضغط Enter لتسجيل الدخول"

## Design tokens

- Warm background `#f5ebe0`
- Accent `#c45c26`
- Card `#fff9f5`
- Clear contrast, Tajawal font, RTL

## Scope

Phase 1 – Design only. No authentication, no form submission.
