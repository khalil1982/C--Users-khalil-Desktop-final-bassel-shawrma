# 📋 Business Requirements Document (BRD)
## Electron Offline-First Shawarma Restaurant Management System
### نظام إدارة مطعم شاورما - النسخة النهائية المحدثة

---

## 🎯 نظرة عامة

نظام **Shawarma Basel POS** هو تطبيق سطح مكتب **Offline-First** مبني على **Electron**، مصمم خصيصاً لإدارة مطاعم الشاورما بكفاءة عالية، مع التركيز على:
- ✅ العمل الكامل بدون إنترنت
- ✅ السرعة والبساطة في الاستخدام
- ✅ الضبط المالي الدقيق
- ✅ القابلية للتوسع المستقبلي (React Native Mobile)

---

## 🔑 المعلومات الأساسية

### المستخدمون
| الدور | الصلاحيات |
|------|-----------|
| **Admin** (صاحب المطعم) | فتح/إغلاق الورديات، اعتماد الفروقات، إدارة الإعدادات، جميع التقارير |
| **Cashier** (الكاشير) | تسجيل المبيعات، إدخال المصاريف، إغلاق الطلبات |

### التقنيات المستخدمة

| المكون | التقنية الحالية | التقنية المستقبلية |
|--------|-----------------|---------------------|
| **Desktop** | Electron | Electron |
| **Frontend** | HTML5 / CSS3 / JavaScript | HTML5 / CSS3 / JavaScript |
| **Backend** | Node.js | Node.js |
| **Database** | SQLite 3 | SQLite 3 |
| **Authentication** | bcrypt | bcrypt |
| **Mobile (Future)** | N/A | **React Native + Expo** |
| **Shared Code** | N/A | **JavaScript/TypeScript (70-80%)** |

## 🌟 لماذا React Native للموبايل؟

### مقارنة مع Flutter

| المعيار | React Native ✅ | Flutter ❌ |
|---------|----------------|------------|
| **اللغة** | JavaScript/TypeScript (نفس Electron) | Dart (لغة مختلفة) |
| **مشاركة الكود** | 70-80% مع Electron | 0% (كود منفصل تماماً) |
| **منحنى التعلم** | سهل (نفس التقنية) | صعب (تعلم لغة جديدة) |
| **فريق التطوير** | فريق واحد (JavaScript) | فريقان منفصلان |
| **الصيانة** | أسهل (كود مشترك) | أصعب (كودان منفصلان) |
| **التكلفة** | أقل (كود مشترك) | أعلى (تطوير منفصل) |
| **الوقت** | أسرع | أبطأ |

## 📊 قاعدة البيانات (12 جدول)

### الجداول الأساسية:
1. **Users** - المستخدمين (مع تشفير bcrypt)
2. **Sessions** - الجلسات النشطة
3. **Shifts** - الورديات

5. **Orders** - الطلبات

7. **Products** - الأصناف

9. **Expenses** - المصاريف
10. **Purchases** - المشتريات
11. **Cash_Differences** - الفروقات المالية
12. **Audit_Log** - سجل التدقيق

## 💡 مميزات استخدام React Native مع Electron

### 1. توحيد التقنية (Unified Stack)
```
Desktop (Electron)     Mobile (React Native)
──────────────────     ─────────────────────
JavaScript/TS    ←──→  JavaScript/TS
React (optional) ←──→  React Native
Node.js          ←──→  JavaScript Core
SQLite           ←──→  SQLite
```

### 2. مشاركة منطق الأعمال (Shared Business Logic)
```javascript
// packages/core/services/OrderService.js
// هذا الكود يعمل على Desktop و Mobile
export class OrderService {
  async createOrder(orderData) {
    // نفس الكود تماماً
  }
}
```

### 3. هيكل المشروع (Monorepo)
```
shawarma-basel/
├── packages/
│   ├── core/          # 70-80% كود مشترك
│   ├── desktop/       # Electron فقط
│   └── mobile/        # React Native فقط
```
